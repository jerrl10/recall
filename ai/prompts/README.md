# Shared AI Prompts

This directory is the canonical location for reusable AI workflows.

The goal is to avoid maintaining separate prompt logic for OpenCode, Claude Code, Codex, and future clients.

Current commands:
- `/learn`
- `/note`
- `/decision`
- `/lesson`
- `/today`

Today they may operate through filesystem access.

When Recall MCP is ready, preserve the user-facing commands and replace the implementation with semantic MCP tool calls.
